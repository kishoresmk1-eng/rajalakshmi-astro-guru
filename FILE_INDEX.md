### 1️⃣1️⃣ **config.txt**
**What it is**: Centralized configuration reference
**What it contains**:
- Contact information

- Social media links

- Email settings
- CDN versions
- Image paths

**How to use**:
- Reference for all customization needs
- Don't edit this file directly
- Use it as a checklist of what needs updating

### 1️⃣2️⃣ **.htaccess**
**What it is**: Server configuration file
**What it contains**:
- GZIP compression rules
- Browser caching rules
- Security headers
- Redirect rules
- CORS settings

**When to use**:
- Upload to hosting if using Apache
- Not needed for Netlify or GitHub Pages
- Improves performance and security

### 1️⃣3️⃣ **robots.txt**
**What it is**: Search engine instructions file
**What it contains**:
- Search engine crawling rules
- Sitemap location
- Bot blocking rules
- Crawl delay

**How it helps**:
- Tells Google how to index your site
- Required for good SEO
- Upload to root directory

### 1️⃣4️⃣ **sitemap.xml**
**What it is**: XML sitemap for SEO
**What it contains**:
- URLs of all website sections
- Last modified dates
- Change frequency
- Priority levels

**Before deploying**:
- Edit domain from `yourdomain.com` to your actual domain
- Submit to Google Search Console
- Helps with indexing
